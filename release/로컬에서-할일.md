# 로컬에서 할 일 (앱인토스 출시까지)

> Claude Code 에 붙여넣을 프롬프트는 [로컬-작업-프롬프트.md](./로컬-작업-프롬프트.md) 에 있습니다.

이 앱의 기준값입니다. 콘솔 등록값과 **글자 하나까지** 같아야 합니다.

| 항목 | 값 | 자리 |
|---|---|---|
| 앱 ID (appName) | `todaymyheart` | `granite.config.ts` |
| 앱 이름 (displayName) | `오늘의 마음 한장` | `granite.config.ts` |
| 제출 파일 | `todaymyheart.ait` | `npm run build` 결과 |

---

## 0. 준비 (컴퓨터마다 한 번)

Node 20 이상(22 권장)과 git 이 있어야 합니다. `nvm` 을 쓰면 `nvm use` 로 22 가 잡힙니다(`.nvmrc`).

```bash
git clone https://github.com/frakenfire/-.git todaynote
cd todaynote
npm install
npm run doctor        # Node · SDK · 앱 설정 · 배포 키 · 제출 파일을 한 번에 점검
```

> 저장소 이름을 `todaynote` 로 바꿨다면 주소만 `https://github.com/frakenfire/todaynote.git` 로 쓰면 됩니다.
> GitHub 가 옛 주소를 자동으로 넘겨줘서 어느 쪽이든 동작합니다.

배포 키 등록 (업로드할 때만 필요, 한 번만):
```bash
npx ait token add     # 콘솔에서 받은 API 키를 붙여넣기 → ~/.ait/credentials 에 저장
```

## 1. 화면 보기

| 어디서 | 명령 | 비고 |
|---|---|---|
| PC 크롬 | `npm run dev` → http://localhost:5173 | 광고는 mock(항상 보상 성공) |
| 폰 토스 샌드박스 앱 | `npm run dev:toss` | PC 와이파이 IP 를 자동으로 찾아 `granite dev`(8081) + vite(5173) 를 띄웁니다. 폰과 PC 가 같은 와이파이여야 합니다 |
| 폰 실제 토스 앱 | `npm run build` → `npx ait deploy` | 업로드가 끝나면 `intoss-private://todaymyheart?_deploymentId=...` 링크가 나옵니다. 이 링크(또는 콘솔 QR)로 폰에서 엽니다 |

- IP 를 자동으로 못 찾으면 `npm run dev:toss -- 192.168.0.12` 처럼 직접 넣으세요.
- 샌드박스에서 빈 화면이면 PC 방화벽이 8081·5173 포트를 막고 있는지 먼저 보세요.
- **광고·저장·공유는 실제 토스 앱(세 번째 줄)에서만 제대로 확인됩니다.**

## 2. 개발자센터에서 받을 값

https://developers-apps-in-toss.toss.im

| 받을 것 | 필수 여부 | 안 넣으면 |
|---|---|---|
| **API 키** (배포 키) | 업로드하려면 필수 | `ait deploy` 를 못 합니다 |
| 앱 아이콘 URL | 선택 | 앱 안에서 이 주소를 쓰는 자리에 그림이 깨집니다. 스토어 목록 아이콘은 콘솔에 올린 로고라 무관합니다 |
| 광고 그룹 ID (리워드형) | 선택 | 광고 없이 나갑니다. 두 번째 쪽지·궁합·다른 고민이 전부 무료로 열리고 수익은 없습니다 |
| 알림 템플릿 코드 | 선택 | 알림 동의 줄이 화면에 안 나옵니다 |

- 콘솔 앱 이름은 정확히 **`오늘의 마음 한장`**, 앱 ID 는 **`todaymyheart`** 입니다.
  이름이 다르면 심사 반려 1순위입니다.
- 아이콘 파일은 준비돼 있습니다 → `release/app-icon-600.png` (600×600)
- 광고 그룹은 1개만 만들어 세 지면에 다 써도 됩니다.

## 3. 받은 값 넣기 (명령 한 줄)

```bash
node scripts/apply-console-values.mjs \
  --icon=https://static.toss.im/appsintoss/받은주소.png \
  --ad-group=받은광고그룹ID \
  --noti-template=받은템플릿코드
```

- 가진 값만 넣으면 됩니다. 형식이 틀리면 스크립트가 막습니다.
- 광고 그룹을 지면별로 따로 받았다면 `--ad-group` 대신 `--ad-note=... --ad-compat=... --ad-concern=...`

확인:
```bash
npm run check:release                      # 남은 값 목록 (개발 중엔 남아 있어도 정상)
node scripts/check-release.mjs --release   # 제출 직전: 꼭 필요한 값이 빠졌으면 실패
```

## 4. 빌드 → 업로드 → 폰 확인 → 검토 요청

```bash
npm run verify             # 타입체크 + 테스트 + 빌드 + 가드 전부
npm run build              # todaymyheart.ait 생성
npx ait deploy -m "메모"   # 업로드. 끝나면 intoss-private:// 테스트 링크가 나옴
```

폰 토스 앱에서 테스트 링크로 열어 아래 4가지를 직접 눌러 보세요.

- [ ] 보상형 광고가 실제로 뜨고, **끝까지 본 뒤에만** 잠긴 화면이 열리는지 (중간에 닫으면 안 열려야 정상)
- [ ] 결과 카드 저장 → 폰 갤러리에 이미지가 저장되는지
- [ ] 공유하기 → 토스 공유창이 뜨는지
- [ ] 상단 노치 / 하단 홈바에 내용이 가리지 않는지

문제가 없으면 콘솔에서 해당 버전의 검토를 요청합니다.
