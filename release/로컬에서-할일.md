## 1. 개발자센터에서 값 4가지 받기

https://developers-apps-in-toss.toss.im

| 받을 것 | 어디서 | 생김새 |
|---|---|---|
| **앱 ID** | 앱 만들기 → 생성 후 표시 | `todaynote-ab12` 같은 영문 슬러그 |
| **아이콘 URL** | 앱 설정 → 아이콘 업로드 | `https://static.toss.im/appsintoss/....png` |
| **광고 그룹 ID** | 수익화/광고 → 보상형(리워드) 광고 그룹 생성 | 발급되는 ID |
| **배포 API 키** | API 키 / 배포 키 메뉴 | 배포할 때만 씀 |

**아이콘 파일은 이미 준비돼 있어요** → `release/app-icon-600.png` (600×600) 그대로 업로드하면 됩니다.

**광고 그룹**은 4개를 따로 만들어도 되고(심층리포트 / 카드저장 / 다시뽑기 / 궁합),
귀찮으면 **1개만 만들어서 네 군데 다 써도** 동작합니다.

---

## 2. 받은 값 적용 (명령어 한 줄)

파일을 직접 열어 고칠 필요 없어요. 스크립트가 알아서 넣습니다.

```bash
node scripts/apply-console-values.mjs \
  --app-name=발급받은앱ID \
  --icon=https://static.toss.im/appsintoss/받은주소.png \
  --ad-group=발급받은광고그룹ID
```

광고 그룹을 지면별로 따로 만들었다면 `--ad-group` 대신:
```bash
  --ad-detail=... --ad-save=... --ad-retry=... --ad-compat=...
```

> 형식이 틀리면(대문자 앱ID, http:// 아이콘 등) 스크립트가 막아줍니다.

## 4. 빌드 & 배포

```bash
npm run verify          # 타입체크 + 테스트 + 빌드 (전부 통과해야 함)
npx ait build           # .ait 번들 생성
npx ait deploy --api-key 발급받은키
```

`ait deploy` = 토스에 "검토해 주세요" 하고 올리는 것. 사람이 검수하고 승인하면 켜집니다.

---

## 5. 검토 제출 전에 실기기에서 꼭 확인 ⚠️

**이 4가지는 실제 토스 앱 안에서만 검증됩니다.** (원격 환경에서는 시뮬레이션만 가능)

콘솔의 **QR / 샌드박스**로 본인 폰 토스앱에서 열어서:

- [ ] **보상형 광고가 실제로 뜨는지**, 그리고 **끝까지 본 뒤에만** 심층 리포트가 열리는지
      (중간에 닫으면 안 열려야 정상)
- [ ] **결과 카드 저장** → 폰 갤러리에 실제로 저장되는지
- [ ] **공유하기** → 토스 공유창이 뜨는지
- [ ] 상단 노치 / 하단 홈바 영역에 콘텐츠가 안 가리는지

문제 없으면 검토 제출하면 됩니다.
