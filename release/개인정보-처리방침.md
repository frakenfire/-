# 오늘쪽지 뽑기 — 개인정보 처리방침

최종 수정일: 2026년 8월 19일

## 한 줄 요약

**이 앱은 서버가 없습니다.** 입력한 정보는 전부 이용자의 기기 안에만 저장되며,
어디로도 전송되지 않습니다.

## 1. 수집하는 정보

| 항목 | 수집 목적 | 필수 여부 | 저장 위치 |
|---|---|---|---|
| 생년월일 (양력) | 사주 팔자 계산 | 선택 | 기기 내 저장소 |
| 태어난 시각 | 시주(時柱) 계산 | 선택 (모름 가능) | 기기 내 저장소 |
| 띠 · 별자리 선택값 | 운세 결과 개인화 | 선택 | 기기 내 저장소 |
| 기분 선택값, 뽑기 기록 | 결과 생성 및 연속 기록 | 선택 | 기기 내 저장소 |

이름, 연락처, 이메일, 주소, 결제 정보는 **수집하지 않습니다.**
로그인 절차가 없으며 이용자를 식별하는 계정을 만들지 않습니다.

## 2. 저장 방식과 보관 기간

모든 정보는 이용자 기기의 브라우저 저장소(localStorage)에만 기록됩니다.
서버로 전송하지 않으므로 사업자는 이용자의 생년월일을 알 수 없습니다.

보관 기간은 이용자가 직접 정합니다. 다음 중 하나를 하면 즉시 삭제됩니다.

- 앱 안의 **[내 사주 → 생년월일 삭제]**
- 앱 안의 **[전체 기록 삭제]**
- 토스 앱 데이터 삭제 또는 토스 앱 삭제

## 3. 제3자 제공 및 처리위탁

이용자의 입력 정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다.

앱 내 광고 노출과 실행 통계를 위해 토스(비바리퍼블리카)가 제공하는 미니앱 기능을
사용합니다. 이 과정에서 사업자가 이용자의 생년월일 등 입력 정보를 토스에 전달하는 일은
없습니다. 토스 앱 자체의 정보 처리에 관하여는 토스의 개인정보 처리방침을 따릅니다.

## 4. 이용자의 권리

이용자는 언제든지 저장된 정보를 확인하고 삭제할 수 있습니다.
사업자가 보관하는 정보가 없으므로 열람·정정·삭제 요청은 앱 내에서 즉시 처리됩니다.

## 5. 만 14세 미만 아동

만 14세 미만 아동의 개인정보를 별도로 수집하지 않습니다.

## 6. 서비스의 성격

이 앱이 제공하는 사주·운세 해석은 전통 명리 규칙에 따른 **오락용 콘텐츠**입니다.
의학적·법률적·재무적 판단의 근거로 사용해서는 안 됩니다.
